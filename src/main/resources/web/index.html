Access

Every request needs an RBAC login with the service's RBAC role. Log in once with PUT /rbac/session (Rbac: Explicit, Rbac: Kerberos, Rbac: Oauth or Rbac: Token) and send the returned Rbac: Cached header on every other request. A Token login is not renewed: log in again with a new token once it expires. Admins can use the admin panel.
