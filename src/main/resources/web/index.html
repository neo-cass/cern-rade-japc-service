Part of the RADE framework

Access

  1. Join the rade-services-japc-users e-group. Only its members can use the service.
  2. Log in once with PUT /rbac/session, sending Rbac: Explicit, Rbac: Kerberos, Rbac: Oauth or Rbac: Token.
  3. Send the returned Rbac: Cached header on every other request. A Token login is not renewed: log in again with a new token once it expires.

The rade-admins group can use the admin panel.
